## Environments

There are two: a local devnet for development and one public deployment on Midnight preprod.
There is no staging environment and no mainnet deployment.

| | Local | Preprod ("production") |
|---|---|---|
| **Midnight network id** | `undeployed` | `preprod` |
| **Contract address** | New on every `scripts/deploy.ts` run; written to `deployments/undeployed.md` and `.env.local` | `3ce0a48228880fa377d22d364a1ad19fee5cb6e26a8ed80de11d7ab07433ceef` ([record](../../deployments/preprod.md)) |
| **Node** | `midnight-node:1.0.2` in `devnet.yml`, `ws://127.0.0.1:9944` | Midnight's public preprod node |

| **Proof server** | `proof-server:8.1.3` in `devnet.yml`, `http://127.0.0.1:6300` | Each user's own, on their machine. For deployments: local, same image. |

nothing is deployed there.

### What must match within an environment

Most incidents come from one of these being out of step with the others.

| These must agree | Otherwise |
|---|---|
| The network id used by the wallet, the web app, the indexer and the scripts | Addresses do not resolve; wallets refuse to connect |
| `CONTRACT_ADDRESS` in the indexer, the web app and the scripts | The API shows another contract's data, or none |
| The compiled contract in the indexer image and the deployed contract's ledger layout | The indexer cannot parse state and stalls |
| The verifier keys on-chain and the prover keys clients download | Every call to the affected circuit fails |
| The compiled contract in the web app and the keys it downloads | Same |
| The compiler version (0.31.1) across every build of the contract | Different keys from the same source |

### Secrets

| Secret | Where it lives | Controls |
|---|---|---|
| Deployer wallet seed (`MN_TEST_WALLET_SEED`) | The developer machine that deploys. Never on the API host. | The wallet's funds, the contract's admin role and the maintenance authority (upgrades) |
| `.env.<network>.local` | Written by `deploy.ts`, gitignored | Contains the admin seed |
| `.wallet-state/` | Developer machine, gitignored, mode 0600 | Wallet sync state |
| `POSTGRES_PASSWORD` | `deploy/production/.env` on the API host | The indexer database (rebuildable public data) |
| `PINATA_JWT` | `deploy/production/.env`, only with the IPFS profile | Pinning account |

The API host holds no key that can move funds or change the contract. Compromising it exposes
query metadata and lets an attacker serve wrong data or wrong ZK artifacts to clients, but not
alter the chain.
